### 🏆 主要荣誉

- 清华大学**文科资深教授**（2022）
- 第三届**全国十大杰出中青年法学家**
- 清华大学**新百年教学成就奖**
- 北京市高等学校**教学名师奖**
- 教育部人文社会科学研究优秀成果奖 **一等奖**

### 📚 学术影响

出版个人专著 **30 余部**，在《中国社会科学》《法学研究》《中国法学》等期刊发表学术论文 **400 余篇**。代表性著作《刑法学》自 1991 年初版以来，历经七次修订，是中国刑法学领域最具影响力的教科书之一。
